# Calendario PAMM - Post Alexander Magnus Mortem

Un sistema de calendario alternativo con 13 meses de 28 días cada uno, basado en la muerte de Alejandro Magno.

## 🌟 Características

### Funcionalidades Principales
- **Conversor bidireccional** entre fechas gregorianas y PAMM
- **Calendario interactivo** con navegación por meses/años
- **Calculadora de fechas** (diferencias y sumas/restas)
- **Eventos personales** con almacenamiento local
- **Festividades culturales** con sistema de colores categorizado
- **Búsqueda rápida** de fechas y eventos
- **Cuenta regresiva** al próximo año PAMM

### Mejoras Web
- ✅ **SEO optimizado** con meta tags y structured data
- ✅ **Progressive Web App (PWA)** con service worker
- ✅ **Modo offline** con cache inteligente
- ✅ **Diseño responsive** para todos los dispositivos
- ✅ **Accesibilidad mejorada** con ARIA labels y navegación por teclado
- ✅ **Modo oscuro/claro** con detección automática del sistema
- ✅ **Backup/Exportación** de eventos personales

## 🚀 Instalación y Uso

### Para Desarrollo Local
1. Clona o descarga los archivos del proyecto
2. Abre `index.html` en tu navegador web moderno
3. ¡Listo para usar!

### Para Producción
1. Sube todos los archivos a tu servidor web
2. Asegúrate de que el servidor sirva archivos con los MIME types correctos
3. Configura HTTPS si es posible (recomendado para PWA)

## 📱 Atajos de Teclado

| Atajo | Función |
|-------|---------|
| `←` `→` | Navegar mes anterior/siguiente |
| `↑` `↓` | Navegar año anterior/siguiente |
| `Home` | Volver al año actual |
| `T` | Ir a hoy |
| `C` | Ir al conversor |
| `H` | Ir al inicio |
| `K` | Ir a la calculadora |
| `E` | Ir a eventos personales |
| `Ctrl+F` | Activar búsqueda |
| `Ctrl+Shift+T` | Cambiar tema |

## 📤 Backup de Eventos

### Exportar
1. Ve a la sección "Mis Eventos"
2. Haz clic en "Exportar eventos"
3. Guarda el archivo JSON generado

### Importar
1. Ve a la sección "Mis Eventos"
2. Haz clic en "Importar eventos"
3. Selecciona tu archivo JSON de backup
